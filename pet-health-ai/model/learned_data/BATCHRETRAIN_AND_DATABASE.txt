[ส่วนที่ 1: การทำงานปัจจุบันบน VS Code (ก่อนมี Database)]
--------------------------------------------------------------------------------
ปัจจุบันระบบใช้ระบบไฟล์ (File-based) ในการจัดการข้อมูลและเทรนโมเดล:

1. โครงสร้างโฟลเดอร์สำหรับเก็บภาพที่จะสอนโมเดล:
   pet-health-ai/
     └── model/
           └── learned_data/
                 ├── bacterial_dermatosis/   (โรคผิวหนังติดเชื้อแบคทีเรีย)
                 ├── demodicosis/            (โรคเรื้อนเปียก / ไรขี้เรื้อน)
                 ├── dermatitis/             (โรคผิวหนังอักเสบทั่วไป)
                 ├── fungal_infection/       (โรคเชื้อรา / กลาก)
                 ├── healthy/                (ผิวหนังสุขภาพดี)
                 └── hypersensitivity/       (โรคผิวหนังจากภูมิแพ้)

2. ขั้นตอนการใช้งานจริงในปัจจุบัน:
   ขั้นที่ 1: เมื่อได้รูปโรคใหม่ที่มั่นใจ นำไฟล์ภาพไปวางในโฟลเดอร์โรคที่ตรงกัน
   ขั้นที่ 2: เปิด Terminal ในโฟลเดอร์ model แล้วสั่งรัน:
              python retrain_batch.py
              - ระบบจะดึงภาพใหม่มารวมกับภาพเดิม 3,000 กว่าภาพ
              - จำลองสภาพแสงมืดลง 40%, แสงจ้า, เงาบัง, ภาพเบลอ อัตโนมัติ
              - สำรองไฟล์เดิมไว้เป็น _backup.pth
              - อัปเดตไฟล์ mobilenet_model.pth และ efficientnet_model.pth ทันที
   ขั้นที่ 3: เปิดเซิร์ฟเวอร์เพื่อให้หน้าเว็บใช้งานโมเดลเวอร์ชันใหม่:
              python main.py

[ส่วนที่ 2: สิ่งที่ต้องเตรียมในโค้ด ก่อนเปลี่ยนไปใช้ Database]
--------------------------------------------------------------------------------
เมื่อจะย้ายจากการลากวางไฟล์ใน VS Code ไปเป็นระบบฐานข้อมูล (เช่น MySQL / SQLite / PostgreSQL):

1. ออกแบบตารางในฐานข้อมูล (Database Schema):
   ตารางที่ 1: pets (ข้อมูลสัตว์เลี้ยง)
     - id : รหัสสัตว์เลี้ยง
     - name : ชื่อสัตว์เลี้ยง
     - breed : สายพันธุ์ (ใช้คำนวณความเสี่ยงโรคเฉพาะพันธุ์)
     - age : อายุ (ปี)
     - sex : เพศ

   ตารางที่ 2: diagnosis_history (ประวัติการตรวจจากหน้าเว็บ)
     - id : รหัสการตรวจ
     - pet_id : สัตว์เลี้ยงตัวไหน
     - image_path : ที่อยู่ไฟล์ภาพที่อัปโหลด (เก็บใน uploads/)
     - predicted_disease : โรคที่ AI ทำนาย
     - confidence : คะแนนความมั่นใจ (%)
     - created_at : วันเวลาที่ตรวจ

   ตารางที่ 3: verified_training_data (รูปที่จะส่งไป Batch Retrain)
     - id : รหัส
     - image_path : ที่อยู่ไฟล์ภาพ
     - verified_disease : ชื่อโรคที่ถูกต้องแน่นอน
     - verified_by : ยืนยันจากอะไร (เช่น auto_consensus, vet_confirm)
     - is_trained : สถานะการเทรน (0 = ยังไม่เคยเทรน, 1 = เทรนแล้ว)

2. จุดที่ต้องแก้ไขในโค้ด main.py:
   - เมื่อ User อัปโหลดรูป ให้บันทึกรูปภาพลงโฟลเดอร์ uploads/ พร้อมบันทึกลงตาราง diagnosis_history
   - เพิ่มฟังก์ชันเช็กเกณฑ์ความมั่นใจ (Consensus) หากโมเดลทั้งสองตัวตอบตรงกันเกิน 90% ให้เพิ่มข้อมูลลงตาราง verified_training_data อัตโนมัติ (is_trained = 0)

3. จุดที่ต้องแก้ไขในโค้ด retrain_batch.py:
   - เปลี่ยนจากคำสั่งอ่านไฟล์ในโฟลเดอร์ (DATA_DIR.rglob) เป็นคำสั่งยิง SQL:
     SELECT image_path, verified_disease 
     FROM verified_training_data 
     WHERE is_trained = 0;
   - เมื่อเทรนจบ ให้สั่งรันคำสั่งอัปเดตสถานะ:
     UPDATE verified_training_data SET is_trained = 1 WHERE ...;
